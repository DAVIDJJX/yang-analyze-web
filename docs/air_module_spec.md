# 空氣品質模組 — 欄位規格摘要（開發規格）

來源：環境部「環境監測填寫範本」空氣品質資料辭典＋總分類（搭配 115/7/22 版範本）、
官方空白範本 `templates/air_template.xlsx`。
本文件為 js/configs/air.js 的開發依據；輸出格式以官方空白範本標題列為準。

## 輸出工作表

1. `監測點基本資料`（8 欄，與水質完全相同：計畫代碼、書件案號、書件名稱、執行現況、
   施工日期、竣工日期、營運日期、備註）→ **可直接沿用現有案場管理與匯出程式**
2. `空品檢測項目`（**23 欄**，比水質多 2 欄）

## 與水質模組的差異（開發重點）

- 多了 5 個測站/採樣層級欄位：場所編號、採樣地點高度、污染物採樣高度、管制編號、煙道編號
  （高度為固定測站屬性 → 適合放進**測站記憶**；管制編號/煙道編號視 raw data 而定）
- 檢測類別 6 種（工區周界監測常用「周界空氣品質」）
- 沒有「採樣深度/採樣水深」欄
- 常用單位代碼：113=ppm、111=ppb、50=mg/m^3、127=ug/m^3、140=μg/m3
- raw data 來源檔（檢驗室檔名慣例）：`<計畫編號>A<次數>.xls` 的 A 系列檔
  （空氣檢驗報告，常為 .xls 舊格式，SheetJS 可直讀），欄位配置待拿到樣本後定義 parseSheet

## 總分類（空氣品質）

大氣環境、固定污染源、移動污染源、周界空氣品質、室內空氣品質、光污染
