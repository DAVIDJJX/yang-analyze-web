# 填表核對模組（待填表格自動填寫＋核對）

> 對應網站左側「填表核對」頁（`index.html#fill`）。程式碼在 `js/fill/`，單元測試在 `tests/fill/`。

## 1. 用途與流程

每季要把各檢驗室的原始報告（Word、Excel、DocuWorks 掃描檔、PDF）中的數值，
抄到「填寫總表」之類的 Word / Excel 表格中。本頁把這件事自動化：

| 步驟 | 畫面 | 說明 |
|---|---|---|
| ① 原始資料 | 拖曳上傳 | DocuWorks（.xdw / .xbd）、PDF（文字型或掃描型）、Word（.docx）、Excel（.xlsx / .xlsm / .xls / .csv / HTML 表格）、影像（.jpg / .png / .tif …），可多檔混放 |
| ② 待填表格 | 拖曳上傳 | Word（.docx，例：填寫總表）、Excel（.xlsx / .xlsm / .xls）；可多個 |
| ③ 核對 | 自動比對 | 每個空格列出建議值、來源（檔名／頁／表格位置）、原始影像條帶（紅框＝取值儲存格）、比對狀態；可直接修改、改選其他來源、對應測點 |
| ④ 核對完成檔案 | 下載 | 「下載已填寫檔案」＝與上傳的待填表格**相同格式、相同版面**，只把空格填滿；另有核對報告（.xlsx）與全部打包（.zip） |

所有處理都在瀏覽器內完成（OCR 也是），**不會上傳任何檔案**。

## 2. 檔案辨識（為什麼 DocuWorks 現在辨識得到）

`js/fill/filetype.js` 先看**檔案內容**（magic bytes / 內部結構）再看副檔名，
副檔名與內容不符時會提示（例：「副檔名為 .xls，實際為 HTML 表格」）。

DocuWorks（`.xdw`）是富士軟片（Fuji Xerox）的專有格式，一般網頁工具無法讀取。
本工具依實際檔案逆向解析（`js/fill/xdw.js`）：

* 整個檔案是 BER-TLV 結構：檔頭 `[0x60]`，之後是一連串 `[0x61]` 區塊（DocuWorks 採「附加式儲存」）。
* 每頁掃描影像是 `[0x64]` 物件，內含：壓縮代碼（9＝CCITT G4 黑白、7＝低解析灰階背景 DIB）、
  實體尺寸（1/100 mm）、像素尺寸、解析度（點/公尺）、影像資料。
* G4 影像由自製解碼器（`js/fill/ccitt.js`，與 libtiff 逐像素相同）還原，再進入表格辨識。
* 若 DocuWorks 檔不是掃描影像（例如從 Excel 以 DocuWorks Printer 列印產生的向量頁面），
  瀏覽器無法繪製；畫面會提示改用 DocuWorks Desk「匯出 PDF」後上傳（文字型 PDF 可精確取值）。

## 3. 掃描檔辨識流程

1. 解碼頁面影像（XDW：G4；PDF：pdf.js 以 200 dpi 繪製；影像：瀏覽器解碼／TIFF 自製解碼）。
2. 二值化（以 R/G/B 最大值判斷，紅色印章、藍色手寫不會被當成文字）。
3. **表格格線偵測**（`js/fill/grid.js`）：找出水平／垂直框線 → 框線圍出的每個區域就是一格，
   自動處理合併儲存格。
4. **逐格 OCR**（Tesseract.js，繁中＋英文，本地載入 `lib/tesseract/`、`lib/tessdata/`）：
   每格單獨辨識，數字準確度遠高於整頁辨識。表格外的文字列（如「監測位置：○○新城」）也會辨識，作為脈絡。
5. 辨識結果依檔案 SHA-256 快取在瀏覽器（IndexedDB `fillcache`），同一檔再次上傳不用重算。
6. 選中的數值再以「純數字」模式第二次辨識，兩次不一致會標「需核對」。

文字型 PDF 不跑 OCR：框線一樣由影像偵測，文字直接取 PDF 內文（精確）。
Word / Excel 原始資料直接讀表格；Excel 若是本站既有「水質／空氣／噪音」模組認得的報告格式，
另以既有解析器補充精確數值（噪音 L日/L晚/L夜、振動 Lv日/Lv夜、空氣日平均、水質各項）。

## 4. 空格判讀與比對規則

`js/fill/extract.js`、`js/fill/match.js`、`js/fill/dict.js`：

* 每個值（或空格）由所在列左側的標籤＋所在欄上方的表頭＋表格標題／頁面文字推得：
  **測站**、**項目**（SO2、NO2、NOx、CO、O3、THC、NMHC、CH4、PM10、PM2.5、TSP、硫化氫、氨、臭氣、
  噪音 Leq/L日/L晚/L夜、振動 Lv日/Lv夜/Lvmax、氣象、水質項目…）、**統計方式**、**單位**。
* 待填表格的測站取自表格標題（例「表2.1-2 ○○社區空氣品質歷次調查結果彙整」→ ○○社區），
  或同一列的測站欄位（逐筆紀錄式表格）。
* 統計方式對照（可依需要調整 `match.js` 的 `DEFAULT_RULES`）：

  | 待填表格表頭 | 取原始報告的 |
  |---|---|
  | 小時平均值 | 最大小時平均值 |
  | 8小時平均值 | 8小時最大平均值 |
  | 24小時平均值 | 日平均值／24小時值 |

* 單位不同時自動換算（ppb↔ppm、mg/m³↔μg/m³），並註記「單位換算」。
* 「標準」「限值」「檢測方法」「偵測極限」等欄位不會被當成數值。
* 同一空格若在兩份來源找到一致的數值（例如總表的 ppm 值與逐時紀錄表的 ppb 值換算後相同），狀態為「✓ 兩來源一致」；
  不一致則為「⚠ 需核對」並列出其他來源可改選。
* 沒有測站名稱的測點（例：異味報告的測點①～④）會出現在「測點對應」，選一次對應的表格測站即可，
  設定會記住（存在「設定/備份」的備份檔中），下一季同格式報告自動帶入。
* 找不到資料的空格（例：該季沒有噪音原始資料）標「無對應資料」，可手動輸入，
  或用「無對應資料的空格填入 -」一次補齊。

## 5. 輸出

* Word：只在空格的段落中加入文字，字型沿用該格原本的設定（例：Times New Roman／標楷體），
  其他內容（版面、框線、其他段落）原封不動。
* Excel（.xlsx / .xlsm）：直接修改工作表 XML，保留原有格式；數字以數值寫入並保留報告的小數位數
  （例 0.060 不會變成 0.06），`<10`、`ND` 等以文字寫入。
* 舊版 .xls：以 SheetJS 寫回，可能遺失部分格式（畫面會提示，建議先另存 .xlsx）。
* 可勾選「填入處以黃色底色標示」產生複查用版本。
* 核對報告（.xlsx）：每個空格的填入值、狀態、來源檔案與位置、原始文字、OCR 信心度、其他來源。

## 6. 已知限制

* 掃描檔需以 `https://`（GitHub Pages）或 `serve.bat`（`http://localhost`）開啟；
  直接雙擊 `index.html`（`file://`）時瀏覽器禁止 OCR 背景執行緒，畫面會提示。
* OCR 對清晰的印刷表格準確度高；手寫、嚴重歪斜或解析度很低的掃描可能辨識錯誤——
  請以「原始影像」條帶核對，必要時直接修改填入值。
* 舊版 Word（.doc）、PowerPoint 不支援，請另存為 .docx / .pdf。
* DocuWorks 格式為逆向解析，目前支援掃描影像頁（G4 黑白；JPEG/PNG 影像頁依內容自動判斷）。

| `js/fill/xlsxtpl.js` | Excel 表格讀取與寫回（保留格式） |
| `js/fill/dict.js` | 項目／統計／單位詞庫、數值解析、測站名稱相似度 |
